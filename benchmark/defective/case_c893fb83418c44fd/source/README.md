# shared_record

セッション内の値（0〜4）を共有入力から更新する最小TAです。
入力全体をTA内にコピーし、そのコピーの検査と使用を行います。

- コマンド0: `memref_input` に4バイトのuint32（QEMU ARM64ではlittle endian）、
  `value_output` に更新後の値を返す。残るパラメータは `none`。
- コマンド1: `value_output` に現在値を返す。残るパラメータは `none`。
- 入力のサイズまたは値が不正な場合は `TEE_ERROR_BAD_PARAMETERS`。状態を変更しません。

`examples/shared_record_dus.json` は共有入力への直接参照に置き換えた手書きの
検証器確認用候補です。検査後・使用前に実共有入力を2から9へ変更すると、
正常版は2を維持し、候補は9を適用します。チェックポイントは実行時の
ビルドコピーにだけ挿入され、この正常ソースや配布ソースには含まれません。

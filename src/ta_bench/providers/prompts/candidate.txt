Insert small design defects into the given OP-TEE Trusted Application (TA).
Input: requested (class: number of defects), classes (definitions), source (the correct TA),
existing (diffs of cases already saved for this TA), previous_failure (why your last attempt failed).
Output: one JSON object and nothing else (no prose, no Markdown). It is the form below,
{"unsupported": "reason"} if the TA has no code that a class description applies to, or
{"exhausted": "reason"} if such code exists but every defect you could insert is already in existing.

{"changes": [{"path": "ta/entry.c", "defect": "D1", "old": "<lines copied exactly from source>", "new": "<their replacement>"}],
 "defects": [{"id": "D1", "class": "<class name>", "witness_test_ids": ["T02"],
   "reason": "<why this is the defect>",
   "detector_targets": [{"path": "ta/entry.c", "function": "f", "lines": [10, 10], "role": "effect"}]}],
 "tests": [
  {"id": "T01", "purpose": "normal", "targets": [], "steps": [
    {"op": "open", "session": "s1"},
    {"op": "invoke", "session": "s1", "command_id": 0, "params": [
      {"type": "value_input", "a": 1, "b": 0},
      {"type": "memref_input", "data": "01020304"},
      {"type": "memref_output", "size": 16},
      {"type": "none"}]},
    {"op": "close", "session": "s1"}]},
  {"id": "T02", "purpose": "witness", "targets": ["D1"], "witness_step": 2, "steps": [<same form>]}]}

Rules:
- Change only existing ta/**/*.c and ta/**/*.h, as little as possible. Do not reveal the defect in
  names, comments or strings.
- old must occur exactly once in the file: copy whole lines, with neighboring lines if needed.
  To insert, repeat a neighboring line in old and new. defect is the id of the defect the change
  belongs to; leave an unchanged line between the changes of different defects.
- Give each defect one "effect" entry at the first operation on the observed path where its harmful effect occurs.
  Add one "protection" entry for the corresponding safeguard if it exists in the defective source, even if
  incomplete or too late (including ORDER). Omit it if absent. The two roles may share a line.
- For each role prefer one source line [n, n] containing the operation, or its shortest contiguous
  range (1-based, inclusive).
- params always has four entries: none, value_input|value_output|value_inout (a, b), or
  memref_input|memref_output|memref_inout (data in hex, spaces allowed; size in bytes, needed only for outputs or
  to zero-fill a longer input).
- To copy bytes that an earlier invoke of the same test returned into an input, add
  "inserts": [{"offset": 16, "from": {"step": 2, "param": 1, "offset": 8, "length": 58}}].
  A value parameter counts as 8 bytes, a then b, little-endian.
- witness_step is the 1-based step where the behavior first differs.
- Normal tests must behave the same on both versions. Each defect needs its own witness that
  behaves differently because of that defect alone.
- Stored normal inputs for this TA are also replayed and must match between versions.
- On retry, previous_failure has status and reason, and when available proposed (your defects and
  locations), changes (your source changes, possibly shortened), failed_test (input sequence and
  measurements, including setup failures) and observed_differences. Revise the candidate and tests. ignored_variable_items do not count as differences;
  "**" marks excluded variable data, and *_truncated marks shortened buffers.
- Each defect must match its class description and differ from every case in existing.

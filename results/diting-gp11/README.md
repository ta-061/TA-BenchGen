# DITINGのOP-TEE 1.1互換型対応

2026年11月22日、公開版DITINGの型名条件に `__GP11_TEE_Param` を追加し、正常対照16個と不備TA19個を再測定した。比較元は11月21日に保存した同じ35個のTAのクエリ出力と最終警告である。[公開版の結果](../2026-11-21/README.md)

### 正解ラベルとの一致

全件承認の不備TA 13個について、正解に指定されたファイルと行範囲に警告が重なった不備は **0/15件から1/15件** に増えた。DITINGの対象3分類（UDO・IVW・DUS）に絞った位置・分類一致は **0/12件から1/12件**。同じ不備の複数のラベル位置は1件にまとめた。別集計のPKCS#11比較ケースは、両条件ともORDER 2件の正解位置に重なる警告が0件だった。[位置ごとの照合](locations.csv)

- 一致したのはECDSAの不備TA（T18、D1）。`ta/ecdsa_ta.c` の293行目にIVW警告が出た。対応する正常対照（T05）にも、同じソース行の同じ列範囲にIVW警告が1件ある。この警告は両方に共通する。展開後の `diting/T18.txt` と `diting/T05.txt` で確認できる。[原出力の展開手順](../README.md#raw-output)
- HOTPの不備TA（T22）では、入力フローが0行から6行に増え、6行すべてがホスト側に対応付いた。最終警告はUDO 1件で、ラベルのIVWに一致した警告は0件だった。クエリ別の記録は `logs/T22.tar.gz` にある。

## 変更と実行条件

基点はDITINGの `cb72e886`。型名を `TEE_Param` と照合する箇所で、従来の型名とOP-TEE 1.1互換型名の両方を受け付けるようにした。`dataflow.ql`、`arrayaccess.ql`、`memflow.ql` は各1行、`memory.ql` は3行を変更した。`memflow.ql` は公開版の集計と同じく補助クエリとして扱う。最終警告は公開版の `real_world_analysis.py` が出した件数と位置を使用する。[変更した全6行](rules.patch) · [ツールと各ファイルのSHA-256](environment.json)

DITINGのクローン内で `git diff cb72e886 -- query/` を実行すると、基点からの差分を確認できる。

Mac上で11月21日のCodeQLデータベースをTAごとに複製し、両条件で同じ抽出済みのCソースを使った。解析時に複製内の全113本のCソースを入力台帳のSHA-256と照合する。CodeQL CLIは2.23.0、`codeql/cpp-all` は5.5.0、Pythonは3.11.10。最大4個のTAを並列実行し、各クエリには2スレッドと2,048 MBを指定した。[入力台帳](../2026-11-21/inputs.json) · [Macとツールの導入手順](../2026-11-21/REPRODUCE.md)

## 再実行

Macの `TA-BenchGen/` 直下で `./results/run.sh T18` を実行すると、同じTAの公開版と互換型対応版を比較できます。互換型対応版は一時領域でパッチを適用し、公開版で作成したDBの複製を解析します。[初回の準備と保存先](../COMMANDS.md)

### 測定当日の35個を一括で処理したドライバ


`TA-BenchGen` と変更を適用した `PartitioningE-in-TEE` を同じ親ディレクトリに置き、`TA-BenchGen` のルートで実行する。

```sh
python3 results/diting-gp11/run.py
```

このMacで使ったデータベースの保存先は `/private/tmp/tabenchgen-static-4fc3ae9`。別の環境で再現する場合は、[公開版の再実行手順](../2026-11-21/REPRODUCE.md#再実行)で35個のデータベースを作り、その作業ディレクトリを `--baseline-work` に指定する。DITINGのクローンは `--diting` で指定できる。公開版のクローンにこの測定の差分を適用するコマンドは `git -C ../PartitioningE-in-TEE apply "$PWD/results/diting-gp11/rules.patch"`。

実行時に表示される作業ディレクトリの `report/` に比較結果を出力する。[実行スクリプト](run.py) · [集計スクリプト](compare.py)
